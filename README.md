
# Enterprise PostgreSQL Database Administration Project

## Project Overview

ABC Finance currently uses Microsoft SQL Server for its banking application.

The company faces several challenges:

- Slow database performance
- Manual backups
- No Disaster Recovery
- No High Availability
- No Monitoring
- On-premise infrastructure

## Objective

Migrate SQL Server to PostgreSQL 15 and build a highly available, secure and monitored database environment.

## Technologies

- SQL Server 2022
- PostgreSQL 15
- SSMS
- pgAdmin
- pgloader
- Prometheus
- Grafana
- Git & GitHub

## Project Modules

- Database Design
- SQL Server Development
- Database Administration
- SQL Server to PostgreSQL Migration
- High Availability
- Disaster Recovery

- Performance Tuning
